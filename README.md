# Doggy Daycare Responsive Web App

## Project Overview
A modern, responsive front-end application for a pet service business.

## Key Features
* **Responsive Design**: Mobile-first approach using CSS Flexbox/Grid.
* **Dynamic Booking**: Real-time cost calculation using JavaScript.
* **Interactive UI**: Seamless service selection and navigation.

## Tech Stack
* **Frontend**: HTML5, CSS3, JavaScript (ES6+)
